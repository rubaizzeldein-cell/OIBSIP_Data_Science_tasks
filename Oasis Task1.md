# Task 1: Iris Flower Classification

**Objective:** Explore and visualize the Iris dataset to analyze feature relationships across species.

**Key Steps & Outcomes:**

* **Data Preparation:** Loaded the 150-row dataset into a Pandas DataFrame and mapped the target species.
* **Quality Check:** Confirmed correct data types and zero missing values.
* **Analysis:** Generated descriptive statistics and built a Seaborn pairplot to visualize feature distributions and class separability.
* **Result:** Successfully completed Exploratory Data Analysis (EDA), confirming the data is clean and ready for machine learning models.

**Tools Used:** Python, Pandas, Seaborn, Scikit-learn, Jupyter Notebook.
